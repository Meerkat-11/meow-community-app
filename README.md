# 🐱 냥집사 모임

모바일 우선의 고양이 커뮤니티 웹앱입니다.

## 실행 방법

브라우저에서 바로 열 수 있습니다:

1. 이 저장소를 다운로드합니다.
2. `index.html` 파일을 브라우저로 엽니다.
3. 또는 로컬 서버를 열어 아래처럼 실행합니다:

```bash
python -m http.server 8000
```

그 다음 브라우저에서 `http://localhost:8000`으로 접속하면 됩니다.

## 주요 기능

- 로그인 / 회원가입 (localStorage 기반)
- 메인 홈, 게시판, 채팅, 알림, 프로필
- 게시글 작성/삭제/상세보기/좋아요/댓글/공유/신고
- 검색 기능
- 다크모드
- 관리자 페이지
- 새로고침 후에도 데이터 유지

## 관리자 계정

기본 관리자 계정:

- 이메일: `admin@meow.com`
- 비밀번호: `admin123`

## 데이터 저장

모든 사용자, 게시글, 채팅, 알림, 설정은 `localStorage`에 저장됩니다.

## 참고

이 프로젝트는 서버 없이 동작하도록 설계되었으며, 나중에 API 서버와 데이터베이스를 연결하기 쉽게 구조를 정리해 두었습니다.
